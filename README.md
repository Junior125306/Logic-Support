# Logic语言支持

这是一个为Logic脚本语言提供语法高亮和基本语言支持的VS Code扩展。

## 功能

此扩展为Logic脚本语言（`.logic`文件）提供以下功能：

* 语法高亮支持
* 代码片段支持
* 括号匹配
* 自动完成括号、引号等

![功能预览](https://logic-6365.obs.cn-north-4.myhuaweicloud.com/preview.png)

## Logic语言简介

Logic是一种基于Java的解释性脚本语言，专为企业级业务快速开发和动态扩展而设计。它具有以下特点：

* 与Java深度集成，支持无缝互操作
* 轻量化语法，融合了JavaScript和Python的语法风格
* 解释执行机制，支持动态加载和即时执行
* 模块化与扩展性，适合业务逻辑的快速扩展与变更

## 语法特性

Logic支持以下语法特性：

* 多种数据类型（number、string、boolean、array、object、null）
* 字符串使用双引号`"`或`$`定义
* JSON对象和集合操作
* 条件表达式和多条件判断
* 循环（each循环、forEach循环）
* Lambda表达式
* 异常处理（try-catch）
* 入参校验（validate）
